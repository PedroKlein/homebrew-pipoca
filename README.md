# homebrew-pipoca

Homebrew formula and cask for [Pipoca](https://github.com/PedroKlein/pipoca).

```sh
brew install pedroklein/pipoca/pipoca
brew install --cask pedroklein/pipoca/pipoca-app
```

`pipoca` is the command-line server for macOS and Linux. `pipoca-app` is the desktop app for Apple silicon Macs, which bundles its own `pipoca` and updates itself. Both are updated here by Pipoca's release workflow.
